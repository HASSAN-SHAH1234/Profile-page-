**Name:** Hassan Bukhari

## Project Description
A responsive personal profile webpage created using HTML, external CSS, and Bootstrap.

## Requirements Included

- HTML structure with:
  - Header
  - Introduction
  - Hobbies list
  - Image
  - External link
  - Table
  - Profile card
- External CSS:
  - Colors
  - Fonts
  - Box model
  - Borders
  - Shadows
  - Responsive styling
- Bootstrap:
  - Responsive grid
  - Navbar
  - Buttons
  - Card
  - Responsive table
  - Badge
- Responsive layout for desktop and mobile screens.

## How to Run

Open `index.html` in a web browser.

Bootstrap is loaded through the Bootstrap CDN, so an internet connection is needed for Bootstrap styling/components.
